# Security policy

Tanu is pre-release software and should not yet host sensitive or irreplaceable content.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue, discussion, or pull request.
Use GitHub's **Report a vulnerability** form in the repository's Security tab. If private reporting
is unavailable, open a public issue titled `Private security contact requested` without technical
details or sensitive information so a maintainer can arrange a private channel.

Include the affected revision, impact, reproduction conditions, and any suggested mitigation. Do not
access other people's data, degrade a service, or retain data while researching a report.

## Supported versions

Tanu does not have a stable release yet. Security fixes are made on the current `main` branch only.
Production operators will need an explicit support policy before the first stable release.
